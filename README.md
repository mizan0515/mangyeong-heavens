# 만경 - 서로 다른 천국

[독서판 열기](https://mizan0515.github.io/mangyeong-heavens/)

본편 「귀환의 서」, 외전 「안감의 지도」, 인물 연작 「거인들의 유언」과 후일담 「낙원 이후」를 함께 읽는 창작 세계 자료집입니다.

이야기, 인물, 세계 기록과 원전의 연결을 왼쪽 탐색 메뉴와 검색으로 살펴볼 수 있습니다. 읽기 위치, 책갈피와 표시 설정은 사용하는 브라우저에 저장되며, 「내 기록」에서 내보내고 가져올 수 있습니다.

이 사이트는 독립된 HTML 문서로 구성됩니다. GitHub Pages는 `main` 브랜치의 루트에서 게시합니다.

원문과 창작물의 권리는 각 권리자에게 있습니다. 이 저장소에는 별도의 재사용 라이선스를 부여하지 않았습니다.
